# R0 Candidate C — Godot reimplementation

This experiment reproduces the same synthetic R0 behavior entirely in Godot.

Its purpose is comparison, not an assumption that Emerald should be rewritten.

It must match the common scenario exactly and record:

- implementation effort;
- debugging ergonomics;
- testability;
- Android integration quality;
- presentation productivity;
- divergence risk versus the authoritative Vanilla+ codebase.
